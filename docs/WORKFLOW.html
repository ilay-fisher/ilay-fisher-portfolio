Portfolio build board

One manager agent plans, writes contracts, reviews and merges. Worker agents (Claude Opus 5.5) each own one workstream in its own git worktree, write tests first, and deliver one pull request. The manager writes no application code.

Rules: AGENT_RULES.md · Interfaces: CONTRACTS.md · Copy: CONTENT.md · Reports: reports/

Workflow

0 · BriefManager gathers profile data, asks the owner, creates repo, Firebase project and contracts.
1 · ResearchWorker R finds the exact technique for every animation.
2 · FoundationWorker F scaffolds tooling, design tokens, shared libs, CI and a stub per section.
3 · FeaturesFive workers in parallel, one worktree each.
A HeroB About / Experience / ContactC SafeSurf demoD Drone demoE X-Ray demo
4 · Integration QAWorker Q checks the merged page: visuals, performance, accessibility, mobile.
5 · ShipManager verifies on localhost, deploys to Firebase Hosting, later connects the Cloudflare domain.

Per-workstream loop

  1. Manager sends a brief: goal, owned paths, port, acceptance criteria.
  2. Worker creates a worktree and branch from origin/main.
  3. Worker writes failing tests and commits them (test:).
  4. Worker implements until lint, typecheck, unit, build and e2e pass (feat:).
  5. Worker verifies visually with Playwright screenshots and writes a report.
  6. Worker opens a PR and reports to the manager. It does not merge.
  7. Manager reviews the diff, the tests and the screenshots. Requests changes or merges.
